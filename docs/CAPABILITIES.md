The registry increment extends the API and the standalone SDK shares its validator; the Studio adds console authoring and publication on top of them without any new server authority. Studio drafts start from the five synthetic `contracts/examples` patterns or a blank workflow, up to 20 named drafts per workspace and project stay in the browser, and a version the listed registry versions already hold with other content is flagged with a free version to use; the registry still decides admission. The contract validator does not run code, contact providers, resolve credentials, install a package, verify publisher identity, or authorize a business action. Check results and any unresolved failures are recorded separately in [VALIDATION.md](VALIDATION.md); planned capability must not appear as a current product claim.

Airgap mode disables cloud semantic calls, identity mail, and external incident alerts. Offline organization onboarding records an operator attestation separately from mailbox verification. Authenticator MFA works without egress and production operators must enroll it. Secure enrollment delivery, human identity checks, encryption-key custody and existing-account recovery still require operator procedures or further work. Without an explicitly supported local semantic evaluator it reports unknown; it does not pretend to provide cloud Jev evaluation offline. Transcript ingestion is not itself speech recognition. Endpoint registration is not an executed integration.

Trace costs retain null for an unavailable measurement and explicit zero when reported. Legacy values preserve their amounts with unknown provenance and are excluded from reported-only monthly subtotals. Measurement counts identify incomplete coverage; these producer assertions are not reconciled billing. Run-result cost gates and the authoritative gateway usage ledger retain their separate conservative handling.
