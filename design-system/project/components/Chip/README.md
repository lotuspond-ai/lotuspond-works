# Chip

A small off-white pill that names one kind of system.

**You provide** the name of a kind of system, in one or two words: "ERP", "Warehouse", "Labs".

- Use Chips on `field` or on `deep`: in a band that lists what LotusPond connects to, or as a label on the thread in a scene.
- Name the kind of system, never a vendor, unless that integration is live.
- A Chip is not interactive. For something a person can press, use a Button or Tabs.
