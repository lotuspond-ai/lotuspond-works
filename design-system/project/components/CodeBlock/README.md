# CodeBlock

Code on `deep-raised`, set in `code`. It is the only place the mono face appears.

**You provide** the code inside `<pre>`, and an optional one-line note in `lp-code__note`.

- Wrap comments in `<span class="c">`, strings in `<span class="s">` and keys in `<span class="k">`. Leave everything else in `on-deep`.
- Put a CodeBlock on a `deep` Sheet. On `surface`, give it `space-4` of room on every side.
- Long lines scroll inside the block; the page never scrolls sideways.
- When the code shows something that is not released, say so in the note.
