# Steps

A numbered sequence of three or four steps, for things that really happen in order.

**You provide** an ordered list. Each item has a short title in an `<h3>` (verb first: "Connect your systems") and one or two sentences in a `<p>`.

- Use Steps only when the order is real: a setup flow, how a person gives permission. For a set of equal points, use columns under a rule instead.
- The numbers are `brand-text`, never tomato.
- Put Steps on `surface`, in the left five columns, beside one visual in the right seven.
- Keep to four steps at most. If there are more, the process is two processes.
