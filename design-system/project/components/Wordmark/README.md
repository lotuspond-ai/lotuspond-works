# Wordmark

The company name set in the display face, ending in a tomato dot. Until a logo file exists, this is the logo.

**You provide** nothing for the company mark. For a product lockup, add the product name in a `<b>`: it is set at weight 400 beside the 700 company name.

- Write it "LotusPond", one word, capital L and P.
- The dot is `accent-mark` and sits on the baseline. Don't remove it, move it or recolour it. It is the one tomato mark allowed on `field`.
- Set the name in `on-field` on `field`, `ink` on `surface`, or `on-deep` on `deep`.
- Keep clear space of one dot-width times three on every side. Smallest size: 18px.
