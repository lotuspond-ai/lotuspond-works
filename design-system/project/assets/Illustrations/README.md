The LotusPond illustration set. Every picture follows the one-thread rules in the brand book.

| File | Use it for |
| --- | --- |
| `hero-stage-wide.svg`, `hero-stage-narrow.svg` | The home page hero scene, desktop and phone. On the page they are inline, so the seeds can move |
| `tangle-to-bloom.svg` | Agents working inside messy systems |
| `a-person-decides.svg` | Approvals and human decisions |
| `on-the-record.svg` | Audit trails and history |
| `many-into-one.svg` | Connecting business systems (Works) |
| `where-records-live.svg` | Connecting health record sources (Health) |
| `one-then-the-rest.svg` | Starting small and growing |
| `in-your-hands.svg` | Trust, control and security |
| `the-journey.svg` | Wide closing strip: from tangle to a bloom in a hand |
| `the-handoff.svg` | Wide closing strip: one hand passing work to another |

Each file is a flat SVG in brand colours with its ground included, so it needs no ink colour from the page. In every picture the bloom sits on an off-white disc or on paper, never on sage. New pictures are drawn with `tools/build_illustrations.py` in the website folder, which holds every shape.
